Быстрый запуск (двойной щелчок)
    Расписание_началка.cmd     — начальная школа, 1–4 классы.
    Расписание_основное.cmd    — основная и старшая школа, 5–11 классы.
    Расписание_вся_школа.cmd   — вся школа одной таблицей.

    PDF кладётся в out и открывается автоматически. Тот же результат из
    консоли: .venv\Scripts\python.exe generate.py beginners|basic|all
    (ключ --no-open — не открывать файл, -o <папка> — другая папка).

Позиционные
    json_path — путь к Расписание_структура.json.
Общие
    -o, --out <путь> — каталог для PDF. По умолчанию out.
    --part <beginners|basic|all> — часть школы. По умолчанию all.
    --day <1..5|пн..пт|all> — день недели. По умолчанию all.
Представление

    --view <classes|teachers|rooms> — что в колонках. По умолчанию classes.

    --cell-info <full|teachers|rooms|classes> — вторая строка ячейки. По умолчанию full.

    --lesson-time <none|short|both> — что в колонке «Урок». По умолчанию none.

Холст и лист

    --canvas <a0|a1|a2|a3|a4|a5|letter|legal> — логический размер таблицы. По умолчанию a3.

    --canvas-orientation <landscape|portrait> — ориентация холста. По умолчанию landscape.

    --size <a0|a1|a2|a3|a4|a5|letter|legal> — формат страницы PDF. По умолчанию a3.

    --orientation <landscape|portrait> — ориентация листа. По умолчанию landscape.

Размеры ячейки

    --cell-width <число> — множитель ширины. По умолчанию 1.0.

    --cell-height <число> — множитель высоты. По умолчанию 1.0.

Шрифты и интервал

    --font-subj <число> — шрифт предмета, pt. По умолчанию авто.

    --font-info <число> — шрифт второй строки, pt. По умолчанию 0.75 × font-subj.

    --line-density <число> — межстрочный интервал, 0.5…1.5. По умолчанию 0.85.

Справка

    -h, --help — показать параметры и выйти.
